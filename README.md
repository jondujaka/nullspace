# NULLSPACE Website

Headless Shopify website built using Shopify Hydrogen and deployed on Shopify Oxygen.
[www.null-space.eu](https://null-space.eu/)



## Stack

- Remix
- Hydrogen
- Oxygen
- GraphQL
- TypeScript
- Vite


## Getting started

**Requirements:**

- Node.js version 18.0.0 or higher

```bash
npm i
```

## Creating environment
```
npx hydrogen env pull
```
After following the instructions to login with the shopify account, this will create an `.env` file with the necessary secrets

## Building for production

```bash
npm run build
```

## Local development

```bash
npm run dev
```
